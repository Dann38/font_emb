# font_emb
## Классификация шрифтов

**Программно реализуемые**

1.  **По начертанию**

-   Тонкий

-   Нормальный

-   Жирный

2.  **По наклону**

-   Наклонный

-   Не наклонный

3.  **Моно или нет**

-   Моно

-   Не моно

4.  **Дополнительные свойства**

-   Капс (заглавные буквы)

-   Выделенный (текстовыделитель)

-   Подчеркивание

-   Зачеркивание

**Нужен шрифт**

5.  **По засечкам**

-   Гротески (без засечек)

-   Антиквы (классические засечки)

-   Брусковые (мощные засечки)

6.  **По схожести с рукописными**

-   Схожи с рукописными

-   Печатные

7.  **По форме**

-   Круглый

-   Прямоугольный
